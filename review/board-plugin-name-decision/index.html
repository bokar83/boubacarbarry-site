Name: Rook — decided 2026-09-04

Chess piece, and the collective noun for a group of rooks (the bird) is "a parliament." That is the whole hook: it ties straight to governance and counsel without spelling either word out.

The repo, README, manifest, and both posts below have all been swapped on this word — 23 mechanical occurrences, per docs/prds/advisory-board-plugin/NAME-SWAP.md in the agentsHQ repo. Done, verified, reinstalled and run once end to end.

Kitchen Cabinet

The real idiom for a leader's informal trusted advisors, but read as a category more than a product. Not chosen.

Counsel

Install handout

Plain numbered steps for someone who has never used a Claude Code plugin:

  1. Open Claude. New to Claude Code? Type "Help me set up Claude Code" and follow the prompts.
  2. Click Customize in the left sidebar, then the Plugins tab.
  3. Top right: click Add, then Add marketplace.
  4. Type bokar83/rook into the box, click Sync — don't press Enter, ignore repo suggestions.
  5. Rook appears in the list — click Install.
  6. Start a new conversation — it won't appear in one already open.
  7. Say: "Help me set up my board of advisors."

Terminal-path alternative:

Terminal commands

claude /plugin marketplace add bokar83/rook /plugin install Rook@Rook
