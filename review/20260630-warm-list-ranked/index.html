Method & traceability

  • Geo inferred only from explicit text signals in Company/Position (Salt Lake city names, Utah cities, known Utah-HQ employers, BYU/UVU/U-of-U/SUU/WGU). No external lookups, no guessing. Absent any signal → Unknown, never a fabricated city.
  • Seniority bucketed from title keywords: Owner/Founder/CxO/Partner/President → Owner; VP/Director/Head → VP; Manager/Supervisor/Lead → Manager; else IC.
  • Warmth from connect-date recency (under 6mo = 3, under 2yr = 2, under 4yr = 1, older = 0).
  • Reachability = Email if an address is present (97 rows), else DM. Binary, never blocks.
  • Scores are percent of each lane's max (Workshop/Audit max 54, Ghostwriting 51). Tier cuts: A ≥70, B 45–69, C <45.
  • No messages were drafted-as-final and nothing was sent. This is the working artifact for the manual outreach pass.
