How the overlay was re-tuned, and why. The first version of this draft sat on the dusk grove, where nothing in the painting glowed, so the code hunted for the busiest parts of the image and dropped glyphs into the canopies. Run that same logic on this painting and it does the wrong thing twice over: it targets exactly the branches that already carry gold line work, so the overlay duplicates the art, and the result reads as clutter rather than as a second layer. So the placement rule is now inverted. The code still measures how busy every cell of the frame is, but it keeps the cells that are empty, and it grows a clearance margin around anything busy so no glyph crowds the silhouette. What that leaves is open sky, the gaps between the limbs, and the dark ground. Glyphs are also fewer and larger, they scale up as the surrounding area gets emptier, and the brightest band of the horizon is excluded so nothing sits in the glare. Net effect: roughly a fifth of the glyph count of the old version, deliberately placed, reading like a slow constellation around a tree that is already lit.

How the effect actually works

The site you liked layers a <canvas> over a looping background video. Every frame it draws the video into a tiny hidden canvas, reads the pixels back, and turns each cell of that grid into a character whose brightness matches the pixel underneath. The picture is still there; you are just seeing it through type.

Both drafts use that same read-the-pixels core. What changes is what gets done with the number:

  • Draft 1 adds a second measurement, edge density, and then uses it backwards. It finds every structurally busy part of the frame, grows a margin around it, and draws only in what is left. The painting keeps its own light; the overlay occupies the space around it.
  • Draft 2 inverts the relationship differently. The overlay starts as the whole picture and retreats, so the painting is the reward rather than the backdrop.

None of this is copied code. I have not seen theirs. This is the technique rebuilt.

Honest notes and what is missing
