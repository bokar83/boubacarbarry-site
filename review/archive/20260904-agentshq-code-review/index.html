TL;DR

Executive conclusion

agentsHQ has real defensive controls, but identity enforcement is inconsistent. Telegram and Djeli retain fail-open defaults, while several state-changing “personal” HTTP routers intentionally have no application-layer authentication. Localhost binding and CORS reduce some exposure; neither proves caller identity. The repository itself records that this configuration assumption already failed once in production.

Findings

HIGH AHQ-01 — Telegram authorization fails open

Evidence: handlers.py:219-226, handlers_ritual.py:88-93,214-217, and handlers_approvals.py:974-978 reject only when ALLOWED_USER_IDS produces a non-empty set. startup_check.py:17-24 does not require it. docker-compose.yml:193-212 documents the prior incident.

Action: fail closed, require the setting when Telegram is enabled, and add negative tests for absent/empty/malformed values.

HIGH AHQ-02 — Mutating routers lack authentication

Evidence: personal research, contact board, Upwork board, mover notes, cash-generation decisions, content-review decisions, and review-checklist modules declare a no-auth posture. They are mounted at app.py:201-220 without router-level dependencies.

Action: apply a shared authentication dependency to state-changing routers. CORS is not authentication; explicitly classify signed public webhooks/forms as exceptions.

HIGH AHQ-03 — Djeli token bypass is designed in

Evidence: handlers_djeli.py:61-85 accepts spoofable Origin/Referer headers without a token and skips authentication when DJELI_TOKEN is absent. The upload cap is 500 MB.

Action: require a signed session or secret for every write; use Origin only as CSRF context; add edge/application quotas.

MEDIUM AHQ-04 — TLS verification disabled

Evidence: upwork_job_scanner.py:200-210,309-328 disables TLS while sending session cookies; quick_audit.py:154-163,363-383 disables TLS for site fetches.

Action: restore certificate verification or repair the CA chain. Never combine credentials with CERT_NONE.

MEDIUM AHQ-05 — Secret scanner has broad blind spots

Evidence: scan_secrets.py:13-24 has a narrow fixed pattern list; lines 62-91 skip all docs, all .env*, and every SKILL.md/AGENT.md.

Action: use entropy/history-aware scanning and narrow reviewed allowlists; scan generated artifacts and history.

MEDIUM AHQ-06 — Floating build inputs

Evidence: unpinned base image, apt packages, hyperframes, model revision, broad Python ranges, and floating GitHub Action tags.

Action: pin digests/SHAs/lockfiles/hashes, generate an SBOM, and review automated dependency bumps.

MEDIUM AHQ-07 — No repository-wide deterministic CI gate

Evidence: GitHub workflows do not invoke repository-wide pytest, type checking, linting, SAST, or dependency audit. Existing targeted tests are useful but not universally enforced.

Action: require a fast fail-closed unit/security/static-analysis gate; expose slower integration results separately.

MEDIUM AHQ-08 — Complexity and duplicate security agents

Evidence: seven control-plane modules total 27,736 lines. Both agents/security-agent/security_agent.py and agents/security_agent/security_agent.py exist and materially differ.

Action: declare one canonical implementation; characterize large modules before splitting stable responsibility boundaries.

LOW AHQ-09 — Caller-supplied shell test command

Evidence: skills/coordination/proposal.py:74-82,178-194 exposes test_cmd and executes it with shell=True.

Action: use argument vectors or allowlisted test profiles; severity rises if untrusted tasks can set this value.

Sankofa Council

THE CONTRARIAN

The fatal flaw is treating missing configuration as permission after that exact assumption already failed in production.

THE FIRST PRINCIPLES THINKER

The real question is “who may cause state or spend?” Answer it once at ingress; CORS, hostnames, and obscurity are not identity.

THE EXPANSIONIST

Generate a route-policy inventory and fail CI whenever a mutating route lacks an explicit public/authenticated/webhook classification.

THE OUTSIDER

A new operator cannot tell which security agent is canonical or which personal routes are publicly reachable. Security knowledge is scattered through historical comments.

THE EXECUTOR

Start with negative tests for absent credentials and a mutating-route inventory. Establish the contract before changing behavior or refactoring.

CHAIRMAN SYNTHESIS

HOLD for targeted hardening, then re-review. Require an explicit policy on every mutating ingress, fail closed on missing security configuration, and enforce those properties in required CI. Address reproducibility and decomposition as separate follow-on work.

MONDAY MORNING

Create one failing test matrix for missing/empty/invalid credentials across Telegram, Djeli, and every mutating board router.

Open question: Should personal board routes be public-domain reachable at all, or live behind authenticated private access?
