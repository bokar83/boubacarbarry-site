D. The reusable methodology (store-agnostic)
  1. Freeze a reference, then verify it stays frozen. Declare the canonical tree; the pre-reorg tree becomes an immutable reference with a written endgame.   2. Review is universal; whole-move is the most common REVIEWED outcome, never a default skip. (Boubacar's reframing.) Every source folder gets a real item-level review. Most coherent folders CONFIRM as move-whole — that is a conclusion the review earns, not a bypass. Mechanical tests (dump-names, counts) PRIORITIZE review order; they never replace review. Only a handful of folders are true RECEIVERS (magnets: Impots, the entity parent, the business cluster, media canon, the Vaults) where items from other folders land individually. The empty-folder discoveries here (2 "legacy units" with zero files) are what universal review buys you. Operational scoping (external-review addition): universal review is HIERARCHICAL, not exhaustive-per-file — coherent folders get a real but LIGHT review (inventory-level: names, counts, types — confirming whole does not require opening every file); the expensive per-item routing pass is reserved for catch-all, flagged, and receiver folders. This is not optional at this Drive's real scale — 544,630 files (measured by the independent sweep): exhaustive per-file review would genuinely explode Drive API rate limits and container memory caps (the same failure class as this session's two documented bulk-fetch incidents).
  3. Topic magnets + retrieval-ordered routing, swept twice: by folder name (with a bilingual/synonym search-resolution layer) and by content pattern (with a second-signal requirement to kill false positives).
  4. Place in Phase A, dedup in Phase B, never together. Every placement emits a receipt (source ID, dest ID, counts, hash check, verify result). No receipt, no operation.
  5. Dual-home the un-dissolvable, shortcuts-first. Immutable Vault for historical transfer units (admission checklist + logged), copy-outs routed by the same tree that routes everything else; Drive shortcuts by default, physical copies only for small high-integrity documents; exactly ONE canonical live home per item, always stated.
  6. Coverage ledger as a per-item deliverable. Every source gets a manifest line with its disposition and its measured gap count — including LEAVE and EMPTY rows — so nothing can silently vanish between plan and execution. Independent enumeration beats inherited bookkeeping: this audit re-derived every prior finding from raw data and found three new ones.

Standing guardrails: mutations by immutable ID; verify-after-state; stop-on-anomaly; media units atomic; sensitive folders opaque IDs; dev-junk exclusion list; two-phase landing; agents never delete; bulk enumeration = folders-first, then chunked resumable file sweeps with checkpoints, never one giant fetch inside a production container.
