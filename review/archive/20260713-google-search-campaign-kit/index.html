Google Search campaign to catch people actively searching for AI help — pointed at the July 30 seat

This is the channel Meta cannot do: someone in Sandy types "ai classes near me" or "ai for small business owners" into Google, and your ad is there. TL;DR ▾

  • One Search campaign, geo = Salt Lake County + 15 mi around Sandy UT, $20/day, start on Maximize Clicks. Small budget, tight local intent, clicks-first so it actually spends and gathers data fast.
  • Three ad groups by search theme: (1) Local AI class, (2) AI for small business / how-to, (3) Which tool / is it worth it. Keywords are mostly phrase + exact match to protect the budget.
  • Hard negatives are the whole game on a paid in-person seat: block free, jobs, certification, degree, python, coding, kids, udemy, coursera, online course so you never pay for free-hunters or career-changers.
  • Destination = the same seat page paid Meta uses (catalystworks.consulting/w/ads) with Google UTMs. High-intent searchers go straight to the seat.
  • One prerequisite you must not skip: Google does NOT use the Meta pixel. You need a Google Ads conversion action firing on /seat/thank-you. Exact steps below. It does not block launch — start on Maximize Clicks now, wire tracking in parallel.
  • Reality check: local "AI class" search volume is thin. Expect a low but very high-intent trickle, not a flood. This is a cheap, reversible test that also leaves you a reusable Google conversion asset for every future workshop.

Can this be set up programmatically? (asked and answered) ▾

No — not from here. There is no Google Ads API access or credential on this machine, and Google Ads has no simple paste-in import for a full campaign the way you would import a CSV of keywords only. So the campaign has to be built by hand in the Google Ads web UI. That is why this page exists: it is the complete, copy-exact spec so the manual build takes 20-30 minutes and nothing is guessed.

What Google Ads editor DOES let you bulk-paste: the keyword lists and the negative list (paste straight into the keyword boxes). Everything else — campaign settings, ad groups, the responsive ad, assets, conversion action — is point-and-click. All of it is spelled out below in the order the UI asks for it.

1. Campaign structure ▾

Campaign settings

Type: Search (uncheck "Search Partners" and "Display Network" — keep it pure Google Search).

Goal: "Website traffic" (or "Sales" once the conversion action exists).

Networks: Google Search only.

Languages: English.

Location (geo)

Target: Salt Lake County, Utah + a 15-mile radius around Sandy, UT (add both; overlap is fine).

Location option: set to "Presence: people in or regularly in your locations" — NOT "presence or interest". This stops paying for people worldwide merely searching about Utah.

Budget

$20/day (about $300 across the run). Enough to gather signal on thin local volume without overspending before July 23.

If it barely spends after 3 days (very likely on ultra-local terms), that is a volume signal, not a budget problem — see the timeline note.

Bidding — start on Maximize Clicks

Start: Maximize Clicks with a manual max CPC cap of $2.50. Best for a small budget with little/no conversion history — it spends and gathers click data immediately and does not need conversion tracking to function.

Do not start on a conversion-based strategy (Max Conversions / Target CPA): with near-zero conversions it will barely serve. Switch to Maximize Conversions only if the conversion action collects 15+ conversions (unlikely in this short run).

Why Maximize Clicks over Manual CPC here: both give budget control, but on a 2-week, low-volume, first-run local campaign, Maximize Clicks gets you out of the gate faster and self-adjusts bids under the cap. Manual CPC is the fallback if you want to hand-tune a single keyword later. The CPC cap is what protects you either way.

7. Conversion tracking — the one prerequisite (Google ≠ Meta pixel) ▾

Read this first. The Meta Pixel (1826865671807664) that tracks your Meta ads does nothing for Google. Google needs its own conversion action. Without it, Maximize Clicks still runs and you still get seats — you just can't see cost-per-seat inside Google and can't later switch to conversion bidding. So: launch now, wire tracking in parallel, do not let tracking block the launch.

Exact steps — Google Ads conversion action for the $47 seat

  1. In Google Ads: Goals → Conversions → + New conversion action → Website.
  2. Enter the domain catalystworks.consulting. If it can't auto-detect, choose "Create conversions manually using code."
  3. Create one action: Category Purchase, name it Workshop Seat ($47), Value 47 USD, Count One. Mark it a Primary conversion.
  4. Google gives you a Google tag (gtag.js) + an event snippet. The Google tag goes on every page of the site; the event snippet fires only on /seat/thank-you (the page shown after a successful Stripe checkout — same page the Meta Purchase already fires on).
  5. Simplest install if the site uses Google Tag Manager already: add the Google tag as a GTM tag on All Pages, and a "Google Ads Conversion" tag triggered on Page View where Path contains /seat/thank-you. No GTM? Paste gtag on all pages and the event snippet on the thank-you page template only.
  6. Verify before trusting it: install the free Google Tag Assistant (or Google's Tag Diagnostics), run a real (or test) checkout to /seat/thank-you, and confirm the conversion registers. Status in Google Ads will read "Recording conversions" within ~24h of the first real fire.
Faster alternative: if GA4 is already on the site, you can import a GA4 "purchase" conversion into Google Ads (Goals → Conversions → + New → Import → Google Analytics 4) instead of hand-installing gtag. Use whichever is already wired. Either way the trigger is the /seat/thank-you pageview / purchase event.
If you ever point ads at /w/free: also create a second conversion action, Category Lead, name Free Checklist Lead, no value, firing on the free-checklist confirmation. Keep Purchase as the only Primary; set Lead to Secondary so bidding still optimizes toward paid seats.

9. Exactly what you do to launch it ▾

  1. Google Ads account + billing. Use your existing account or create one at ads.google.com and add a payment method. (New accounts sometimes push you into the simplified "Smart" flow — click "Switch to Expert Mode" / "Create a campaign without a goal's guidance" to get the full controls this kit assumes.)
  2. Set up the conversion action (Section 7). Start it now; it can finish verifying after launch.
  3. New Search campaign with the settings in Section 1 (Search only, geo, $20/day, Maximize Clicks + $2.50 CPC cap).
  4. Create the 3 ad groups and paste the keyword blocks (Section 2). Add the campaign-level negatives (Section 3).
  5. Build one responsive search ad per ad group — paste the 15 headlines + 4 descriptions (Section 4). Set the Final URL with the right utm_content per group (Section 5).
  6. Add assets — sitelinks + callouts + structured snippet (Section 6).
  7. Publish. Ads go into review (usually minutes to a few hours). Check day 2-3 that they're approved and serving.
  8. July 23 go/no-go, then pause end of July 29.
That's the whole job: build in the UI, set the conversion action, set the $20/day budget, publish. ~20-30 minutes with this kit open beside you.
