▸5. Visibility (SEO / AEO / GEO) + ads, sequenced

From the 90-day visibility plan. Fix Bing to unlock Perplexity, ChatGPT Browse, and DuckDuckGo. Fix Google to unlock Gemini. One keyword cluster: AI implementation for Utah SMBs. Ads come last.

Order of operations

  • Day 1: measurement first. Verify Google Search Console (DNS TXT) and Bing Webmaster. Baseline crawl with Screaming Frog.
  • Day 1–7: entity stack. Wikidata person + org, GBP create + verify.
  • Day 1–14: technical SEO. Title tags, meta, Core Web Vitals (LCP < 2.5s, CLS < 0.1, INP < 200ms), sitemap, robots, internal links.
  • Day 7–30: the pillar cluster. FAQ master (20 questions), homepage overhaul, first pillar + cluster posts. Two-tier answers (40–60 word direct answer, then 150–250 word depth).
  • Day 7–21: schema. FAQPage, HowTo, Speakable, LocalBusiness.
  • Day 21–90: authority + links. Silicon Slopes News, KSL Tech, Utah Business; 3 podcast transcripts; citations cleanup.
  • Ongoing: GBP reviews, target 15+ by Day 90 (~1.5/week, Thursday reminder).
TargetsDay 30: 5–15% AI visibility. Day 60: 15–30%. Day 90: 30%+ on Perplexity and Gemini. Baseline today is 0 of 30. Weekly 15-min review every Monday.

Paid ads (last, gated)

  • Meta only, $30/day, 3 creatives, 72-hour test, then double the winner.
  • Objective: Traffic to the workshop page (or Purchases once the pixel is installed).
  • Geo Sandy + 15 miles, age 30–60, owner/founder behaviors. Start a weekday morning, no weekend spend.
  • Gate: off until 10+ warm captures exist. Kill at $150 spent / 0 captures.
