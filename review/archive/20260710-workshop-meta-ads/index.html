How to build this (numbered, skimmable)

Do these in order. The whole point of the Duplicate step is that you build each of the 3 creatives (image + headline + primary text) exactly once.

  1. 1Pre-flight check. Open business.facebook.com/accountquality and confirm the Catalyst Works Business Portfolio restriction is cleared. Also consciously confirm you are lifting your own spend freeze today — this is your explicit call, not a default.
  2. 2Create one campaign. Objective = Landing Page Views. Budget optimization = ABO (ad-set-level budgets, not campaign budget).
  3. 3Build Ad Set A first (the control). Audience: Salt Lake County + 15 miles of Sandy, UT, location only, no demographic or interest layering. Daily budget $20. Destination for every ad in this set: catalystworks.consulting/w/ads.
  4. 4Inside Ad Set A, build all 3 creatives. Ad 1 = Creative 1 copy + card-A image. Ad 2 = Creative 2 copy + card-B image. Ad 3 = Creative 3 copy + card-C image. Exact copy for each is in the Creatives section below — paste it in verbatim. Publish Ad Set A and confirm all 3 ads go through review clean before continuing.
  5. 5Duplicate the whole ad set, twice. Use Meta's ad-set-level Duplicate button on Ad Set A. This copies all 3 ads inside it automatically — you do not rebuild any creative. Duplicate twice to get Ad Set B and Ad Set D.
  6. 6Edit only the audience on the Ad Set B duplicate. Change targeting to a 5-mile radius around SLCC Miller Campus, Sandy, UT, location only (no demo layering). Leave the 3 ads inside it untouched. Set daily budget to $20.
  7. 7Edit only the audience on the Ad Set D duplicate. Keep the base geography (Salt Lake County + 15mi of Sandy) but add: age 30-58, plus interests "Small Business," "Entrepreneurship," "Small and medium enterprises." This is the one ad set that breaks your location-only rule on purpose, to test it — included because you gave the go-ahead. Leave the 3 ads inside it untouched. Set daily budget to $15-20.
  8. 8Confirm placements and duration. Placements: Meta Advantage+ (automatic) for all 3 ad sets — no manual placement picks in this test. Run 5-7 days minimum, or until each ad set clears roughly 50 optimization events, whichever is longer. Hard cap the undecided window at 10 days.
  9. 9Publish. You now have 3 ad sets x 3 ads = 9 ads live, all pointed at the same verified, correctly UTM-tagged link. Nothing to build by hand a second time.
  10. 10Do not judge early. No kill decision on any ad set before it clears $50 in spend OR 3 full days, whichever is later. See the Win/Kill Rule section below for exactly when and how to cut or scale.

Win / kill rule

Don't judge early. No kill decision on any ad set before it has spent at least $50 OR run 3 full days, whichever is later. Inside that window Meta's learning phase is still noisy and the numbers will lie to you.

Primary metric: Cost per Landing Page View (CPLPV), since the campaign objective is LPV. Secondary: link CTR, as an early read before enough spend accumulates for CPLPV to settle. Tiebreaker / the number that actually matters: cost per seat (Stripe Purchase event via the pixel), once any ad set produces a sale.

KILL an ad set once past the minimum threshold if its CPLPV is more than 2x the best-performing ad set's CPLPV AND its CTR sits in the bottom half of the set. Reallocate its budget to the leader(s).
KEEP / scale whichever ad set(s) post the lowest CPLPV with the highest CTR. If two ad sets are within roughly 15% of each other on CPLPV, let them run longer before forcing a call — that is noise, not signal.
Hard stop: if total spend across the test hits $300-400 with zero seat purchases and every ad set's CPLPV is elevated, pause everything and revisit the offer or creative rather than continuing to spend blind. No historical CPLPV benchmark exists yet for this account — read the first 2-3 days of real numbers before treating any dollar figure as "too high."

Test duration: 5-7 days minimum, or until each ad set clears roughly 50 optimization events (Meta's own learning-phase exit signal), whichever is longer. Cap the undecided window at 10 days — by then, force a keep/kill call on every ad set even if the signal is imperfect.
