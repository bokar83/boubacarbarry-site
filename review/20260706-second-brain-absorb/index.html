How he actually built it

  • Ran a /last30days skill (credited to Matt Van Horn, Lyft co-founder): live research across Reddit, X, YouTube, and Hacker News for current second-brain practice.
  • Fed Fable 5 three named, real, inspectable reference systems, not vague inspiration: actual repos to study.
  • Had Fable scan his real 35,466-file workspace and synthesize a system combining all of it.
  • Used a /goal self-check loop so Fable kept iterating on its own UI until it actually loaded fast, without lag.
QMD: Query My Docs
github.com/tobi/qmd · Tobi Lütke, Shopify
Local-first: BM25 full-text + vector semantic search + LLM re-ranking, local models, exposed as an MCP server.
GBrain
github.com/garrytan/gbrain · Garry Tan, Y Combinator
Memory as markdown in a git repo. Self-wiring knowledge graph: every write extracts entities and typed edges with zero LLM calls.
Graphify
github.com/safishamsi/graphify · YC-backed (S26)
Whole-project AST extraction (code, docs, PDFs, transcripts) into a queryable graph, outputting graph.json, an interactive visualization, and a written report.

06

Worth adopting, flagged honestly

Already built: the brain.js pattern (score before opening, section before whole file, pointer-follow before giving up) and a live-generated visual map are both shipped now, not just flagged as gaps. QMD, GBrain, and Graphify were each read directly and adapted, not ported wholesale.

Already covered before this build: tiered, curated persistent memory: agentsHQ's approach here was already more mature than what this video showed, and it stayed that way.

Resolved this session: no longer an open unknown

Whether the Postgres memory table's ranking is functionally like brain.js or just superficially similar: benchmarked against a real baseline (grep), same method Jay used (token count + latency via /context). Genuine wins on 3/5 real questions, one documented miss, one retracted false-miss. Not asserting more than the numbers show.

Evaluated and correctly NOT built

pgvector consolidation (collapsing tsvector / Qdrant / QMD-local into one surface) was gated on this benchmark showing vector recall as the actual bottleneck. It didn't: the real miss was QMD's BM25 keyword layer, not semantic recall. The 2026-05-10 design spec's deferral holds. Not building it speculatively.
