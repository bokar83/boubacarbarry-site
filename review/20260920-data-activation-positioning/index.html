7. The anonymizer: what it actually is today

You named this as something we built, and you are right. I went and found it rather than writing copy around a thing I had not read. Here is what it actually does, because the copy above has to be true.

It exists, it runs, and it has a window you can open. Checked first-hand, not relayed: its own working tree, thirty modules, the test suite passing, and the full loop proven end to end on a real file. Read a document, classify the fields, mint stand-ins, substitute, verify, hold at a gate you approve, write a receipt, and reverse it afterwards. It works on all four of the formats in scope. Thirty-one real defects were found and fixed on the way, several of which would have corrupted a deliverable silently. There is now a desktop window wrapping the whole thing, so it is not a command line any more.

The design point that matters for copy is that it is selective, not blanket. Identity fields get consistent fake stand-ins. Business data is preserved exactly as it is, byte for byte. That is the whole reason the analysis still works afterwards. A scrubber that makes everything unmatchable would hand back a useless dataset.

The anonymizing, the key creation and the reversal all run with no network at all, on your machine. Only the already-anonymized version goes to a cloud model. If it cannot confidently classify a field, it refuses and emits nothing rather than handing back a half-anonymized file.

Two sentences we may NOT write yet, and one word we may never write.
  • Never "unidentifiable", never "anonymous", never a compliance claim. The tool's own spec is explicit: anonymized is not unidentifiable, and it reduces exposure rather than conferring a legal status. Any page in your name that implies otherwise is a problem you do not want.
  • No claim that it has been run on a real client's data. Built and tested is true and the copy can carry it. What has not happened is the trial against a real corpus, and its own run log says plainly, in its own words, that until that exists no real client document should go through it. So the site copy above describes how the work is set up, in present tense, which is true. It does not say "I have done this for clients", which is not yet.

If you want the copy to carry a stronger claim than that, the thing that unlocks it is running the trial, which the last review of it said is the single highest-leverage unblocked move on that whole board.
