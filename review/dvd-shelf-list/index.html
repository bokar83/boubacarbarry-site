DVD shelf list — and why Plex kept saying 763

Rebuilt from what is actually on the drive, not from what Plex was willing to show. The “missing 292 movies” were never missing. Every one of them is on the disk, and almost all were already inside Plex — hidden. Root cause first, then the corrected shelf list.

Nothing is missing. Plex was hiding 140 films you already own by filing them as extra copies of seven other movies.

Plex wants every movie file named Title (Year).ext. The files in Disney Movie Collection are named the other way round — 1994 - The Lion King.avi, year first. Plex could not read a title out of that, so instead of creating a new movie for each file, it attached them to a movie it had already created. It did this by decade. Every 2000s file went onto one entry, every 1990s file onto another, across seven decades.

That is why the count never moved. The scans were not failing — the files were being imported every single time. They just were not becoming new movies. The Lion King, Aladdin, Beauty and the Beast, Tangled, Lilo & Stitch and 135 others are sitting in your library right now, filed as alternate versions of films like 20,000 Leagues Under the Sea.

You can see this yourself in about ten seconds. Open the Movies library, click the All dropdown, choose Duplicates. Seven entries show a large version count — one of them says 61. Those are the seven.

How to fix it — smallest safe step first

untested, so prove it on 7 files

Step 1 — the three-minute test

do this first
Rename only the seven 1960s files, from 1964 - Mary Poppins.avi to Mary Poppins (1964).avi, then scan. If the movie count moves from 763 to about 769 and those films appear on their own, the fix is proven and the rest can follow. If it does not move, nothing has been lost and we take the other route. This has not been tested yet — which is exactly why it is worth three minutes before touching 153 more files.

Step 2 — rename the rest

only if step 1 works
The same rename across the remaining 153 Disney files. This is the same operation already run successfully on 93 files in the Academy Awards folder, so the tooling and the pattern are known. Renaming also solves a second problem quietly: Plex skips folders whose timestamp has not changed, which is why every rescan and both server restarts did nothing at all. Renaming changes the folder, so Plex is forced to look properly.

Step 3 — clear out the seven wrong entries

after step 2
Library menu, then Empty Trash. This removes the seven bad entries once their files have new names. One side effect worth knowing before you click: three of the seven — Cinderella, Pollyanna and The AristoCats — are currently in your Disney collection. Emptying the trash drops them out of it. They come back as fresh entries and need adding to that collection again.

Step 4 — move Phineas and Ferb

separate job
Move that folder out of the Movies location and into the TV Shows library. Unrelated to the Disney problem, kept as its own step so that if something goes sideways it is obvious which change caused it.

The rule that prevents all of this

going forward
One movie per file, named Title (Year).ext. Year in brackets at the end, never at the front. Every symptom in this document traces back to that one line. Checked across the whole drive: the year-first pattern exists in exactly one folder, the Disney one, in 158 of its 160 files. Other folders have messy names full of release tags and those imported fine — so there is no need to go renaming the rest of the library. It is specifically year-first that breaks Plex.

What is proven, what is not, and what nobody has checked

Proven three separate ways. That 140 films are stacked into seven entries was confirmed by reading Plex's own database directly, then independently through Plex's web interface, which returns 61 separate media entries for “20,000 Leagues Under the Sea”, and then by Plex's own Duplicates filter, which flags all seven without being told to. The file counts come from a full listing of the drive compared line by line against the database.

Not explained: why it grouped by decade. The grouping is real and measurable. Why Plex chose decade-sized buckets is not established. There is a genuine anomaly worth naming rather than papering over: the 1928 to 1949 Disney files use the identical year-first naming and imported perfectly as individual movies. Whatever the precise rule is, it does not kick in before 1950. The fix does not depend on knowing why, but this should not be dressed up as fully understood.

The fix has not been run. Nothing on this page has been applied to the library. The rename approach is the best-supported option and there is a successful precedent on 93 other files, but it is untested against this problem, which is why step 1 is deliberately small and reversible.

Nobody has checked whether the other 758 entries point at the right film. They all carry real metadata IDs, which means Plex matched them to something, not that it matched them to the correct thing. Three of the seven bad entries came back as “Disney Atari”, “Rootin' Tootin' Roundup” and “Disney Parks: Disney's Animal Kingdom”, which shows match quality in that folder was poor generally. “No files missing” is not the same claim as “the library is correct”, and only the first has been verified.

Five films have no metadata at all. Duty to God, Les Percussions de Guinee, two Louis de Funes titles, and a Pixar shorts compilation. They are in the library and playable, just unidentified. Harmless, and easy to name by hand if it bothers you.

What was ruled out, so it does not get re-tested. The drive fault was real and is fixed; the disk check came back clean and it was not causing this. Folder nesting was tested by flattening eleven folders and made no difference. Metadata matching was suspected but was never the blocker — unmatched files still get added to a library, they are never dropped. Permissions were not it either, since 921 files from that same drive imported fine.

Earlier versions of this page were wrong in a way worth flagging. They were built from what Plex displayed, and Plex was hiding 140 owned films. The Disney entry previously read “37 owned” when that folder holds 160 files. Building a shopping list on that view risks sending you out to buy films already on the drive. This version is built from the drive itself, for exactly that reason.
