RECOMMENDED BUILD FIRST The stacking pattern all three agents converged on independently

None of the three brainstorms were shown each other's work — all three still landed on the same core idea: a single signal source is noisy, but stacking three signal types produces a short list of near-certain, low-competition prospects. Each layer removes a category of false positive the layer before it can't catch.

LAYER 1
New license / permit / filing
  • Proves the business is real and recent
  • Sources: Utah DOPL, Accela building permits, state SOS/OpenCorporates, FMCSA SAFER, USPTO
+
LAYER 2
"No website found" check
  • Removes anyone who already solved this problem
  • Sources: Google Places missing-website field, SERP gap-check, Wayback/CDX cross-ref
+
LAYER 3
"Has real capital" check
  • Removes anyone who can't actually afford to buy
  • Sources: SBA 7(a)/504 FOIA loans, UCC-1 financing statements, active Meta ad spend

A business that clears all three layers is: real, recently active, provably missing a website, and already spending or borrowing money — the single highest-confidence, lowest-competition combined signal on this entire list. Build the pipeline in that order; Layer 1 sets volume, Layer 2 cuts the list to the true gap, Layer 3 ranks what's left by ability to pay.

Other corrections that made things worse than originally claimed (not in the top 10, but worth knowing before building): Meta Ad Library API is EU-political-ads-only — no US commercial ad API exists, browsing is manual-only; BBB API requires vetted approval, not self-serve; Utah DOPL has a free search box but no bulk export or date-sort (manual data-request process); Accela building permits has no cross-city API — every city runs its own instance; cosmetology/barber boards are name-lookup only, no "new licenses since X" filter anywhere.

Why not just build all 57 (or all 80) since most are free?

  • Real time cost: 200-300+ hours to build and maintain all of them — that time doesn't show up as an invoice, but it's the only currency a solo operator actually spends.
  • Heavy signal overlap: the same contractor shows up in 4-5 lists at once. That's one lead surfaced five times, not five leads.
  • Output flooding: a solo operator can act on roughly 20-30 outreaches a day. Running 30+ live pipelines produces far more candidates than one person can ever contact — the backlog itself becomes the failure mode.
  • Geography multiplication: most of these sources are single-state or single-city (Accela is literally one API per city). "57 sources" is really "57 x however many metros you try to cover at once."
  • Real dollar costs exist despite the "free" framing: Google Places Enterprise SKU, UCC searches ($15-30 each in some states), OpenCorporates bulk data ($2,250-12,000+/yr), CoStar ($5-40K+/yr).
