The eligibility rule

All four, no exceptions. Time alone must never graduate anything.

  1. Not on the damage list. One wrong call is unrecoverable, and no amount of history changes that.
  2. Not self-referential. Does not change the gate, the approval path, the permission files, or a hard rule. A class that can graduate itself makes every other gate decorative.
  3. Reversible by a revert, with no side effect that survives it.
  4. Ten or more instances, none rejected, spanning 30+ days — and only once rejections are actually recordable.

One recorded rejection excludes a class permanently, not until the next cycle. It re-opens only by an explicit new decision-log entry from you. An agent may never re-open one, and no number of subsequent clean instances does it either.

This page recommends. It never applies. A mechanism that graduated classes on its own could graduate its way past the damage list, and no amount of careful coding makes that safe.

Success criterion for this page itself: a healthy version gets shorter every cycle. If cycle three is longer than cycle one, the review is not working and should be replaced by a filter.
