1. Verdict

The 4-monitor requirement is the filter
AMD mini PCs (Beelink SER8, Minisforum UM890 Pro) are OUT — they cap at 3 native displays

4. Why This Fits the Workload

The Docker multi-container + Postgres + headless Chromium/Playwright + Node stack is RAM- and multi-core-hungry, not GPU-bound — LLM calls route through the OpenRouter API, no local inference, no VRAM need. The GPU in both picks exists only to drive 4 monitors, not for compute.

An 8-core/16-thread modern CPU + 32GB (upgradeable to 64GB via SO-DIMM) comfortably runs the concurrent stack. Socketed RAM is the single most important spec fixing the actual pain point today. Both picks leave a free USB3/USB4 + wired-ethernet path for the future NAS.

5. Paths Rejected, With Why

AMD mini PC + DisplayLink dongle

4th display unreliable as a daily-driver — flickers, driver overhead, software-compressed output. Not worth it just to save on the Intel/Arc alternative.

DIY build

No cost advantage at $1,000 — an 8700G build runs ~$1,150–1,200, doesn't beat prebuilt, adds assembly risk for zero gain given not a hardware assembler.

Laptop

Soldered RAM repeats the exact current pain, can't cleanly drive 4 externals, rejected for a stationary home workload.
